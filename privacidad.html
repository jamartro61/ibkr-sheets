Política de privacidad de IBKR Sheets

Última actualización: 21 de septiembre de 2026.

Finalidad

IBKR Sheets es una aplicación de uso personal que utiliza las API de Google para acceder a hojas de cálculo de Google Sheets necesarias para su funcionamiento.

Acceso a datos de Google

La aplicación accede a datos de Google Sheets únicamente con la autorización del propietario de la cuenta y exclusivamente para leer, actualizar y procesar las hojas de cálculo utilizadas por la aplicación.

Uso y almacenamiento de los datos

Los datos obtenidos mediante las API de Google se utilizan únicamente para las funciones propias de la aplicación. La aplicación no vende ni utiliza estos datos con fines publicitarios.

Las credenciales OAuth necesarias para mantener el acceso autorizado se almacenan en el sistema local donde se ejecuta la aplicación.

Compartición con terceros

IBKR Sheets no comparte con terceros los datos obtenidos mediante las API de Google, salvo cuando sea necesario para el propio funcionamiento de los servicios de Google utilizados.

Usuarios

IBKR Sheets es una aplicación de uso personal y no ofrece registro ni acceso público a otros usuarios.
